# My Portfolio

A modern, responsive portfolio website built with React, Node.js, and Material-UI. This project showcases my skills, projects, and experience as a full-stack developer.

![Portfolio Preview](https://img.shields.io/badge/React-18.2.0-blue) ![Node.js](https://img.shields.io/badge/Node.js-18.x-green) ![MUI](https://img.shields.io/badge/Material--UI-5.14.0-purple)

## 🚀 Features

- **Responsive Design** - Optimized for all devices
- **Modern UI/UX** - Clean and professional interface using Material-UI
- **Project Showcase** - Detailed presentation of my work
- **Smooth Animations** - Enhanced user experience with subtle animations

## 🛠️ Built With

### Frontend
- **React** - Frontend framework
- **Material-UI (MUI)** - React UI component library
- **HTML5** - Markup language
- **CSS3** - Styling and animations
- **JavaScript (ES6+)** - Programming language

### Backend
- **Node.js** - Runtime environment
- **Express.js** - Web application framework
- **MongoDB** - Database (optional)
- **REST API** - API architecture

### Additional Technologies
- **Git** - Version control
- **Netlify** - Frontend deployment
- **Railway** - Backend deployment
